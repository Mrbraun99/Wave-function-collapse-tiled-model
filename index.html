Wave function collapse (tiled model)

About project

This project explores procedural generation using the Wave Function Collapse algorithm. Once you upload your desired tiles using the Upload tile images button, the program automatically generates their rotated versions, filters out any duplicates, and analyzes their border pixels to detect which tiles can be placed next to each other. Although the program tries to generate these rules automatically, you have the option to manually adjust them using the built-in editor, which will be discussed in the Editor section below. To help you get started quickly, I've prepared a demo tileset that you can load by clicking the button below. The tiles used in this demo are from The Coding Train, where you can also find an excellent video explaining the algorithm in detail.

Once you’ve loaded the demo, click the Generate button that appears to start the procedural generation. The project features a dynamic, chunk-based generation system, resulting in a virtually infinite world. You can freely explore the map by holding down the right mouse button to pan around the canvas.

Editor

After you upload your tiles, all of the original tiles along with their generated rotated versions will be displayed on the screen. By clicking on any of these tiles, you can bring up the built-in connection editor. If there is a tile you don't need—for example, if you don't want to use a specific rotated version, or if the program failed to detect a duplicate—you can disable it completely. To do this, simply click on the large tile displayed in the center of the editor. This acts as a toggle, allowing you to easily disable or re-enable the selected tile. Surrounding the center tile, you will see four distinct grids corresponding to the four directions. These sections list all the valid neighbour tiles that are allowed to be placed next to the currently selected tile in that specific direction during the generation process. If you want to manually allow a new connection, click the plus button in any of these directional grids. This opens a modal where you can select the additional tiles you want to permit; simply hit the Add button to include them. Conversely, to remove an existing connection, simply click on the unwanted tile in the directional grid. The tile will remain visible but will display a trash bin icon, indicating that the connection is disabled. This action works as a toggle as well, so clicking the disabled tile again will remove the icon and restore the connection. If you want to remove the tile completely from the grid, hold down the CTRL key while clicking. It is important to note that all connection modifications are perfectly symmetrical. Whenever you add or remove a neighbor, the program automatically updates the corresponding tile in the opposite direction, ensuring that no asymmetrical rules can occur.

Once you are satisfied with your manual adjustments, you can export your entire configuration to a JSON file. This saves you from having to set up the rules again from scratch next time. You can easily load this configuration later using the Import button. It is important to note that when importing a configuration file, the program relies strictly on the rules defined in the file, and no automatic matching or calculations are performed.
